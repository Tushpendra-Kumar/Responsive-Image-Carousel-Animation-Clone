## 📌 Overview

An interactive image carousel and slider component featuring fluid animation physics, automatic slide rotation, navigation buttons, and responsive touch adaptation.

---

## ✨ Key Features

- **Smooth CSS3 Transitions:** Hardware-accelerated sliding animations with easing functions.
- **Interactive Controls:** Next and previous slide buttons along with direct indicator dots.
- **Autoplay Engine:** Timed interval auto-advancement with pause-on-hover capability.
- **Responsive Viewports:** Adapts automatically to desktop, tablet, and mobile aspect ratios.

---

## 💻 Tech Stack & Architecture

- **Core Stack:** Semantic HTML5, CSS3 Transforms & Transitions, JavaScript ES6 DOM
